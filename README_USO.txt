ASOCIACIÓN 31 DE ENERO NARCIZA DE JESÚS - MANUAL v1.2.0
=== FORMA RECOMENDADA: PROGRAMA (EXE) ===
1. Copiar la carpeta dist\Modulo Gestion 31 DE ENERO NARCIZA DE JESUS a un lugar
   con escritura (Documentos o USB).
2. Doble clic en Modulo Gestion 31 DE ENERO NARCIZA DE JESUS.exe (tiene el logo).
   Sale el splash vinotinto con el logo (~6 seg) y abre en pantalla completa.
   No necesita Python ni muestra direcciones web.
3. La base asociacion.db se crea junto al exe. Respaldo = copiar ese archivo.
=== FORMA ALTERNATIVA: DESDE CÓDIGO ===
1. Doble clic en iniciar.bat (requiere Python + pip install -r requirements.txt).
=== USO DIARIO (igual en ambas) ===
1. LOGIN: usuario secretaria / clave 31enero2026. Cámbiela en Config.
2. SOCIOS: cédula 10 dígitos. Montos aceptan punto o coma (25.50 o 25,50).
   N° y orden alfabéticos automáticos (sin digitar).
3. REUNIÓN último sábado: generar asistencia/café/mensualidad, cobrar, y al final
   TERMINAR SESIÓN Y GUARDAR (bloquea edición; Reabrir solo para corregir).
   Extraordinarios: otra fecha + título, SOLO pasa lista.
4. CONSULTA por cédula: comprobante formal con logo, firmas y ESPACIO SELLO.
5. CAJA: columna Comprobante/Obs (N° factura). Corte con logo para imprimir.
6. AUDITORÍA: filtra fecha + cédula + tipo. Reporte con logo.
7. CONFIG: integridad (9 chequeos), descargar respaldo .db, clave y logo.
8. Cerrar: botón rojo ⏻ Cerrar programa (arriba a la derecha) apaga todo.
RESPALDO: copiar asociacion.db a USB cada reunión.
